# Υπερκύβος 4D — React

Αριστερά: σκελετός υπερκύβου με 16 κορυφές και 32 ακμές. Δεξιά: **πραγματική τρισδιάστατη τομή** του τετραδιάστατου σχήματος στο επίπεδο `W` που ορίζεις. Η τομή προκύπτει από τις τομές του επιπέδου με τις ακμές του περιστρεφόμενου υπερκύβου· δεν είναι απλώς χρωματισμένο αντίγραφο του αριστερού σχήματος.

## Άνοιγμα στον υπολογιστή

Άνοιξε το `index.html` σε browser με σύνδεση στο διαδίκτυο. Η React και η ReactDOM φορτώνονται από CDN. Δεν χρειάζονται Python, Node, npm, CUDA ή build.

## Χειρισμός

- **Αυτόματη περιστροφή:** ενεργοποίηση ή παύση της κίνησης στις 4D κατευθύνσεις.
- **3D τομή:** εμφάνιση ή απόκρυψη της δεξιάς μορφής.
- **Δείξε 3D κύβο:** σταματά την περιστροφή και θέτει X–W = Y–W = Z–W = 0° και επίπεδο W = 0. Τότε η δεξιά τομή είναι κύβος με 8 κορυφές, 12 ακμές και 6 έδρες. Οι τιμές εμφανίζονται στους ρυθμιστές και στην ένδειξη κάτω από αυτούς.
- Οι τρεις περιστροφές και ο ρυθμιστής **Επίπεδο τομής W** μεταβάλλουν το σχήμα της δεξιάς τομής. Η **4D προοπτική** επηρεάζει την αριστερή προβολή.
- Σύρε με ποντίκι ή δάχτυλο σε οποιαδήποτε όψη για να αλλάξεις κοινή 3D οπτική.

## GitHub Pages

1. Δημιούργησε δημόσιο repository, π.χ. `hypercube-4d`.
2. Ανέβασε τα `index.html`, `.nojekyll` και `README.md` στη ρίζα του branch `main`.
3. Στο **Settings → Pages → Build and deployment**, όρισε **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** και πάτησε **Save**.
4. Μετά τη δημοσίευση, η διεύθυνση θα είναι `https://<username>.github.io/hypercube-4d/`, με τα δικά σου ονόματα χρήστη και repository.

Οδηγίες GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Η οθόνη δείχνει 2D εικόνες. Η δεξιά εικόνα αποδίδει σε 2D την 3D τομή ενός 4D υπερκύβου.
