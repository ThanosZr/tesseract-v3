# Tesseract v3 Codex

Διαδραστική προβολή ενός υπερκύβου 4D με React σε ένα στατικό HTML αρχείο.
Αριστερά: οι 16 κορυφές και 32 ακμές. Δεξιά: επιλογή ανάμεσα στο εξωτερικό
κυρτό περίβλημα της προοπτικής 4D→3D και στην **πραγματική τρισδιάστατη τομή**
του υπερκύβου με υπερεπίπεδο W=s, επίσης προβαλλόμενη με την 4D προοπτική.
Η τομή τονίζεται και αριστερά.

Η τομή υπολογίζεται από τις ακμές του περιστρεφόμενου 4D κύβου, περιλαμβάνει
και οριακές περιπτώσεις όπου κορυφές ή ολόκληρες ακμές βρίσκονται στο επίπεδο,
και παράγει τις έδρες από τους οκτώ κυβικούς θαλάμους.
Η ορατότητα κάθε έδρας υπολογίζεται από τη θέση της 3D προοπτικής
κάμερας και την κανονική της έδρας, όχι από ορθογραφική προσέγγιση.
Το πλήκτρο «Χρώματα / colormaps» ανοίγει δύο ανεξάρτητες παλέτες
(4D σκελετός και 3D σχήμα). Διαθέτει χειροκίνητο χρώμα, Viridis, Plasma και
Coolwarm με αντιστοίχιση στο βάθος της 3D κάμερας.
Το πλήκτρο «Μαθηματική τεκμηρίωση (PDF)» κατεβάζει το συνοδευτικό PDF.

**Όριο απεικόνισης:** η επιλογή «Προβολή» δείχνει το εξωτερικό περίβλημα,
όχι διαφανή απεικόνιση και των οκτώ κυβικών θαλάμων. Η «Τομή» είναι γεωμετρική
διατομή και διαφέρει από τα οπτικά cutouts του Tesseract Explorer.

## Εκτέλεση

Άνοιξε το `index.html` στον browser. Για τη φόρτωση React/ReactDOM
από jsDelivr απαιτείται σύνδεση στο διαδίκτυο. Δεν χρειάζεται build,
Node ή Python. Κράτησε το `hypercube-math.pdf` δίπλα στο HTML για το
κουμπί της τεκμηρίωσης. Το ξεχωριστό `tesseract-v3-codex.html`
που διανέμεται εκτός του ZIP έχει το PDF ενσωματωμένο μέσα στο αρχείο.

## GitHub Pages

1. Δημιούργησε repository, π.χ. `tesseract-v3-codex`.
2. Ανέβασε `index.html`, `hypercube-math.pdf`, `.nojekyll` και `README.md`
   στη ρίζα του `main` (ή του branch που θα ορίσεις για Pages).
3. Settings → Pages → Deploy from a branch → Branch: main → /(root) → Save.
4. Άνοιξε `https://<username>.github.io/tesseract-v3-codex/`.

Προτεινόμενο development branch:
`feat/accurate-3d-slice-colormaps-pdf`.

## Μαθηματική σύνοψη

Η 4D προοπτική είναι P(x,y,z,w) = d(x,y,z)/(d−w), με d>2.
Για τομή στο W=s: πρώτα υπολογίζουμε Q∩{W=s}, έπειτα εφαρμόζουμε
την ίδια προοπτική: P(x,y,z,s)=d(x,y,z)/(d−s).
Η εξωτερική προβολή του γεμάτου υπερκύβου είναι το κυρτό περίβλημα
των εικόνων των 16 κορυφών όσο d−w>0.

Πλήρεις εξισώσεις, απόδειξη και οριακές περιπτώσεις:
[`hypercube-math.pdf`](hypercube-math.pdf).

Έμπνευση και σύγκριση: https://github.com/tsherif/tesseract-explorer
· μαθηματικό υπόβαθρο: https://arxiv.org/abs/1204.3468
