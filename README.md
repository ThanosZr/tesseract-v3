# Υπερκύβος 4D — React

Αριστερά εμφανίζεται ο σκελετός του υπερκύβου (16 κορυφές, 32 ακμές). Δεξιά, από προεπιλογή, εμφανίζεται η **στερεή 3D προβολή**: υπολογίζονται οι εικόνες και των 16 κορυφών με προοπτική 4D→3D και κατόπιν το κυρτό εξωτερικό περίβλημά τους. Οι κρυφές έδρες δεν σχεδιάζονται. Το τελικό 3D στερεό προβάλλεται στην οθόνη 2D.

Από το μενού μπορείς να επιλέξεις **Τομή · επίπεδο W** ως ξεχωριστό πείραμα. Αυτή είναι η τομή του υπερκύβου με ένα υπερεπίπεδο σταθερού W και μπορείς να μετακινήσεις το επίπεδο. Η τομή και η προβολή είναι διαφορετικές πράξεις.

## Χειρισμός

- **Αυτόματη περιστροφή:** ενεργοποίηση ή παύση της κίνησης στα 4D επίπεδα.
- **3D σχήμα:** εμφάνιση ή απόκρυψη της δεξιάς όψης.
- **Δείξε 3D κύβο:** σταματά την περιστροφή, επιλέγει 3D προβολή και θέτει X–W = Y–W = Z–W = 0°. Το εξωτερικό περίβλημα γίνεται κύβος με 8 κορυφές, 12 ακμές και 6 έδρες.
- Οι τρεις 4D περιστροφές αλλάζουν το δεξί σχήμα. Η **4D προοπτική** επηρεάζει τις δύο προβολές. Ο ρυθμιστής **Επίπεδο τομής W** εμφανίζεται μόνο όταν επιλέξεις την τομή.
- Σύρε οποιαδήποτε όψη με ποντίκι ή δάχτυλο για κοινή αλλαγή οπτικής.

## Άνοιγμα στον υπολογιστή

Άνοιξε το `index.html` στον browser. Χρειάζεται σύνδεση στο διαδίκτυο για να φορτώσουν React και ReactDOM από CDN. Δεν απαιτούνται Python, Node, npm ή build.

## GitHub Pages

1. Δημιούργησε δημόσιο repository, π.χ. `hypercube-4d-explorer`.
2. Ανέβασε τα `index.html`, `.nojekyll` και `README.md` στη ρίζα του branch `main`.
3. Στο **Settings → Pages → Build and deployment** επίλεξε **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** και **Save**.
4. Η διεύθυνση θα είναι `https://<username>.github.io/hypercube-4d-explorer/` μετά τη δημοσίευση.

Οδηγίες GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
